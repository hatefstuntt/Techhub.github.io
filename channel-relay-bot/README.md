# ربات بازنشر کانال‌ها (Channel Relay Bot)

کانال‌های تلگرامی‌ای که معرفی می‌کنی رو زیر نظر می‌گیره، پست‌های جدیدشون رو (متن، عکس، ویدیو و آلبوم) دانلود می‌کنه، به فرمت کانال خودت درمیاره و توی کانالت منتشر می‌کنه.

## چه کار می‌کنه
- **خوندن با حساب خودت** (Telethon): هر کانالی که عضوشی، حتی اگه پیش‌نمایش عمومی نداشته باشه، با کیفیت کامل مدیا.
- **پاک کردن ردپای منبع**: آیدی‌ها، لینک‌ها، هشتگ‌ها، خطوط تبلیغ و «ری‌اکت/عضو شو» حذف می‌شن. برای عکس‌ها هم می‌شه نوار واترمارک رو برید و لوگوی خودت رو گذاشت.
- **فرمت کانال تو**: تیتر بولد داخل نقل‌قول، متن داخل نقل‌قول بازشونده، و فوتر ثابت خودت.
- **بازنویسی با Claude (اختیاری)**: متن رو با لحن کانالت بازنویسی می‌کنه و پست‌های فقط-تبلیغاتی رو رد می‌کنه.
- **تأیید قبل از انتشار**: هر پست اول با دکمه‌ی ✅ / ❌ توی پیوی خودت میاد.
- **محدودیت روزانه**: مثلاً روزی ۱ پست، ساعت ۱۲. پست‌ها به‌طور مساوی بین ساعت شروع و پایان پخش می‌شن.
- **بدون تکرار**: هر پست منبع یک بار بررسی می‌شه و یه خبر که توی دو کانال اومده دو بار منتشر نمی‌شه.

## نصب (روی سرور یا کامپیوتری که همیشه روشنه)
1. پایتون 3.10 یا بالاتر.
2. `pip install -r requirements.txt`
   اگه نصب `pyaes` خطا داد: `pip install "setuptools<70" wheel && pip install --no-build-isolation pyaes` و بعد دوباره دستور قبل.
3. از https://my.telegram.org بخش «API development tools» یه `api_id` و `api_hash` بگیر.
4. از ‎@BotFather‎ یه **ربات جدید** بساز. از ربات فروشگاهت استفاده نکن، چون اون وب‌هوک داره و دکمه‌های تأیید بهش نمی‌رسه. ربات جدید رو توی کانالت ادمین کن، با اجازه‌ی ارسال پست، و یه بار استارتش کن.
5. `cp config.example.yaml config.yaml` و مقدارها رو پر کن: منبع‌ها، کانال مقصد، تعداد پست، فوتر.
6. برای بازنویسی با Claude: `export ANTHROPIC_API_KEY=...` و `rewrite.enabled: true`.
7. اجرا: `python3 relay.py config.yaml`. بار اول شماره‌ی تلفن و کد ورود تلگرامت رو می‌پرسه.

## دستورهای ربات (فقط از طرف تو)
- `/status`: وضعیت و تعداد پست امروز
- `/pause` و `/resume`: توقف و ادامه‌ی انتشار
- `/now`: انتشار پست بعدیِ آماده، همین الان

## نکته‌ها
- فایل `config.yaml` و پوشه‌ی `data/` شامل کلیدها و نشست ورود تلگرامت هستن. به کسی نده و توی گیت نذار.
- محدودیت آپلود ربات ۵۰ مگابایته و ویدیوهای بزرگ‌تر رد می‌شن.
- فقط محتوایی رو بازنشر کن که اجازه‌ش رو داری. پیش‌فرض کلمه‌هایی مثل «کرک» و «FRP» فیلتر شدن.

## تست
`python -m pytest -q tests`
